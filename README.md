# gasm14.github.io

Personal portfolio website for Gonçalo Marçalo — Cybersecurity & IAM Engineer.

## 🔗 Live

https://gasm14.github.io

## 🛠️ Tech Stack

- Pure HTML5 + CSS3 (no frameworks, no JS dependencies)
- Hosted on GitHub Pages

## 🚀 Local Development

No build step required. Open `index.html` directly in a browser or use any static server:

```bash
python -m http.server 8000
# Then visit http://localhost:8000
```

## 📝 Content

The site showcases:

*   Professional summary in cybersecurity and IAM
*   Core technical skills
*   Open-source projects (including Job Radar)
*   Certifications and continuous learning
*   Contact information
